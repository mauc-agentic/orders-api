# orders-api

API mínima de pedidos sobre Flask, usada como repositorio de demostración
del **Engineering Modernization Hub** (caso Wenia) para el escenario de
modernización inviable.

Modernización de demo: actualizar `Flask` de `2.0.3` a `3.0.x`, con la
restricción de mantener el runtime en Python 3.7 (`runtime.txt`). Flask
3.0.0 exige `Requires-Python: >=3.8`, lo que hace la modernización
inviable tal como se solicita. Ver `DOCS/11-demo.md` del Hub.
